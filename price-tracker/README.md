# 야놀자 가격 수집기 (price-tracker)

야놀자 검색 결과에서 숙소명과 가격을 자동으로 긁어 CSV / JSONL 로 저장합니다.

## 왜 여기서 안 돌아가나

이 저장소를 편집한 클라우드 세션은 조직 egress 정책 때문에 `www.yanolja.com` 에
접속할 수 없습니다(게이트웨이가 CONNECT 에 403 응답). **PC 에서 직접 실행해야 합니다.**

## 설치

```bash
cd price-tracker
npm install
npx playwright install chromium
```

## 실행

요청하신 조건(속초해수욕장 검색 → **속초굿모닝호텔** / 2026-08-02 1박 / 성인 2명)이 기본값입니다.

```bash
node src/cli.js --show --debug
```

옵션을 바꾸려면:

```bash
node src/cli.js --keyword 속초 --target 속초굿모닝호텔 --checkin 2026-08-02 --nights 2 --adults 2
node src/cli.js --all          # 특정 호텔로 좁히지 않고 전체 목록만
```

| 옵션 | 설명 | 기본값 |
| --- | --- | --- |
| `-k, --keyword` | 검색어 | `속초해수욕장` |
| `-t, --target` | 결과 중 이 숙소를 찾아 객실 가격까지 수집 | `속초굿모닝호텔` |
| `--all` | 목표 숙소 없이 전체 목록만 수집 | 꺼짐 |
| `--no-rooms` | 목표 숙소를 찾아도 상세 페이지는 열지 않음 | 꺼짐 |
| `-d, --checkin` | 체크인 (YYYY-MM-DD) | `2026-08-02` |
| `-n, --nights` | 숙박 일수 | `1` |
| `-a, --adults` | 성인 인원 | `2` |
| `-c, --children` | 아동 인원 | `0` |
| `--show` | 브라우저 창을 띄워 진행 과정을 본다 | 꺼짐(headless) |
| `--debug` | 스크린샷·HTML 을 `debug/` 에 저장 | 꺼짐 |

크로미움을 따로 내려받을 수 없는 환경이면 기존 바이너리를 지정할 수 있습니다.

```bash
CHROMIUM_PATH=/path/to/chrome node src/cli.js
```

## 목표 숙소 찾기

`--target` 은 이름이 정확히 같지 않아도 찾아냅니다.

1. 공백·괄호·특수문자를 지우고 비교 → `속초 굿모닝 호텔` = `속초굿모닝호텔`
2. 부분 포함 → `굿모닝호텔` 로도 매칭
3. 접미어(호텔/모텔/펜션…)를 뗀 핵심어 포함
4. 2글자 단위 겹침 비율 (오타·표기 변형 대응)

일치도 60% 미만이면 "못 찾음"으로 처리하고, 대신 **이름이 비슷한 후보를 가격과 함께** 보여줍니다.
지역 검색 목록에 없으면(정렬·페이지네이션 때문에 누락될 수 있음) **호텔명으로 한 번 더 검색**한 뒤 다시 찾습니다.

찾으면 상세 페이지로 들어가 **객실별 가격**을 수집하고, `대실`/`숙박`을 구분해 따로 기록합니다.

## 결과물

- `data/prices.jsonl` — 실행할 때마다 누적. 날짜별 가격 추이를 비교하는 원본.
  `kind` 가 `listing`(검색 목록) / `room`(객실), `isTarget` 이 목표 숙소 여부.
- `data/<목표숙소>_<체크인>_<수집시각>.csv` — 엑셀에서 바로 열리는 스냅샷 (BOM 포함).

## 오프라인 스모크 테스트

야놀자에 접속하지 않고 `tools/*.html` 픽스처로 추출·매칭 로직을 검증합니다.

```bash
node tools/smoke.js
```

DOM/JSON 추출, 병합, 띄어쓰기 다른 이름 매칭, 할인 전후 가격, 대실/숙박 구분 등 13개 항목을 확인합니다.
사이트 구조가 바뀌어 `src/extract.js` 를 손볼 때 회귀 확인용으로 쓰세요.

## 동작 방식

야놀자는 마크업과 쿼리 파라미터가 자주 바뀌므로 한 가지 방법에 의존하지 않습니다.

1. **URL 파라미터** 후보 4종을 순서대로 시도 (`startDate`/`checkInDate`, `www`/`nol` 호스트)
2. 페이지를 스크롤해 지연 로딩 카드까지 렌더링
3. 세 갈래로 추출한 뒤 숙소명 기준으로 병합·중복 제거
   - `__NEXT_DATA__` JSON 트리 순회
   - 인라인 `<script>` 안에 박힌 JSON 조각 파싱 (app-router flight 페이로드)
   - 화면 카드 텍스트 휴리스틱 (`00,000원` 패턴 + 숙소명 후보 줄)
4. 위 경로가 모두 3건 미만이면 홈에서 검색창에 직접 입력하는 UI 경로로 폴백

첫 실행은 `--show --debug` 로 돌려 화면의 날짜·인원이 의도대로 잡혔는지 눈으로 확인하는 것을 권합니다.

## 수집이 0건일 때

`debug/` 의 스크린샷과 HTML 을 보면 원인이 대부분 드러납니다.

- **봇 차단 / 캡차 화면** → `--show` 로 창을 띄워 직접 통과한 뒤 재실행
- **검색 결과 0건** → 검색어를 `속초` 처럼 넓게
- **마크업 변경** → `src/extract.js` 의 `NAME_KEYS`, `selectors` 목록 갱신

## 알아둘 점

- 화면 가격은 1박 기준이며 할인 전/후가 섞여 나오므로 `최저가`·`최고가`를 함께 기록합니다.
  실제 결제가는 상세 페이지에서 다시 확인해야 합니다.
- 개인적인 가격 비교 용도를 전제로 합니다. 짧은 간격으로 반복 실행하면 차단될 수 있고
  사이트 이용약관에 저촉될 수 있으니, 주기 실행은 최소 수십 분 간격을 권장합니다.
