# 출퇴근 점각 앱 (1단계)

공용 PC에 띄워두고 직원이 **이름 선택 → PIN 4자리 → 출근/퇴근**으로 점각하는 키오스크 앱.
점각 원본은 위변조 방지(해시체인)·자동 백업으로 안전하게 보관되고, 관리자 화면에서 직원·기록을 관리합니다.

## 실행
```
npm install      # 최초 1회
npm start
```
(설치본 만들기: `npm run dist` → NSIS 설치파일 생성. 바탕화면 아이콘으로 쓰려면 이 방식)

## 처음 사용 순서
1. 우측 상단 **⚙ 관리자** → 비밀번호 설정(최초 1회)
2. **직원 등록**
   - 운영관리 앱을 쓰면 **“운영관리에서 직원 가져오기”** (이름·지역·급여형태 자동) → 직원별 **PIN만 설정**
   - 또는 **+ 직원 등록**으로 직접 입력
3. **잠그고 점각화면으로** → 직원이 점각 시작

## 데이터 / 백업 위치
- 데이터: `%APPDATA%\attendance-clock\data`
- 백업: `%APPDATA%\attendance-clock\backup` (30분마다 + 시작 시 자동)
- 관리자 → 설정에서 **데이터/백업 폴더 열기**, **위변조 검사** 가능
- ⚠️ 수정·업데이트 전에는 **백업 폴더를 외장/클라우드에 복사**해 두세요.

## 안전 설계
- 점각 원본(punches)은 **수정·삭제 불가**(append-only). 잘못된 점각은 관리자 **보정 이력**으로만 정정.
- punches·corrections·auditLog는 **해시체인**으로 위변조를 탐지.
- 파일은 임시파일→rename **원자적 쓰기**(쓰는 중 정전에도 원본 보존).
- 야간 자정넘김 근무는 “**열린 근무 세션**” 기준으로 정확히 출퇴근 처리(epoch 계산).

## 운영관리 앱 연동
- 방식: **파일 핸드오프**(서로의 데이터 폴더를 직접 건드리지 않음). 직원 마스터 기준 = **운영관리 앱**.
- 1단계: 운영관리 직원 명단 가져오기(운영관리 직원 id `extId` 보관, 주민번호는 가져오지 않음).
- 2단계 예정: 월별 연장/야간/휴일 시간을 파일로 내보내 → 운영관리 **추가근무(근무표)** 로 반영 → 급여근거.xlsx 자동 반영.

## 단계
- **1단계(완료)**: 점각·직원관리·점각기록 조회·자동백업·위변조검사
- **2단계**: 근무표(예정시간), 연장/야간/휴일·지각/조퇴/결근 집계, 주휴, 관리자 보정 UI, 월마감, 운영관리 근태 내보내기
- **3단계**: 월별 급여반영표 엑셀, 대행사 급여대장 1원 대사
